## The haiku

> Cursor blinks at three
> the log swears nothing is wrong
> yet the bug just grins

Syllables: 5 – 7 – 5. Characters: 77.

The picture is the one every debugger knows: a cursor blinking at 3 a.m., a log file insisting nothing is wrong — and the turn is the bug itself, grinning back at you.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes the haiku to `out/entry.txt` (defaults to `/output/entry.txt`). Python 3 standard library only.
